# 厨房販売率CALC

WinShareの「まちかど厨房（販売）」の販売高・値引高・廃棄高から、日ごとの販売率と、目標（初期値75%）までの差額・必要な作成高を出すページです。

- `index.html` をブラウザで開くだけで使えます（iPhone・PC対応、外部ライブラリなし）。
- タブ：まとめ／作成計画／日別／写真
- 入力した数字と目標%は、そのブラウザに保存されます。
- 写真から数字を読み取る機能：Claudeのページではそのまま使えます。GitHub Pagesでは、写真タブの「読み取りの設定」に自分のAnthropic APIキーを入れると使えます（キーはその端末のブラウザだけに保存）。
